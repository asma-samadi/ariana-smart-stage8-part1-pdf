# Dari and Pashto translations that need native-speaker review

**Status: NOT reviewed.** Every Dari (`prs`) and Pashto (`pus`) string in this project was written by an AI model.
English is the source and the fallback. Nothing below was invented to "fill a gap": where meaning was unclear the English
text was translated as literally as possible, and it is listed here so a human can confirm it.

Do **not** treat the legal and privacy wording in section A as correct until a native speaker (ideally one familiar
with Afghan legal/administrative usage) has read it against the English. This is an educational demo; if it is ever
used with real people, a lawyer should also review the English source.

How to review: compare each row's three columns, edit `frontend/src/i18n/prs.js` / `pus.js`, and run `npm test` in
`frontend/` (it checks key parity, placeholders, script letters and digits).

Generated from the dictionaries at the time of Stage 7 Part 2. Keys are shown exactly as used in the source.

## D. General points for the reviewer

- **Terminology:** ticket (`تکت` Dari / `ټکټ` Pashto), national ID (`تذکره`), passport (`پاسپورت`), "demonstration/educational" (`نمایشی`/`آموزشی`; Pashto equivalents). Confirm these are the terms people actually use.
- **Pashto letters:** the dictionaries use Pashto yeh/e forms (`ي`, `ې`, `ۍ`) and `ګ`; check against the spelling convention you want (a test enforces only the hygiene rules in `test/i18n.test.js`).
- **Digits:** numbers inserted by the app use Persian digits (۰–۹) in Dari and Pashto; static text was converted to match in Stage 7 Part 2. Confirm that Pashto readers in your audience prefer these over Latin digits.
- **Dates:** shown with the Gregorian calendar (not Solar Hijri) and Dari-style month names (`اکتوبر`, `نومبر`...). Some browsers have no Pashto locale data, so Pashto then uses Persian-locale month names and word order. A Pashto reviewer should confirm the month names and the order "year month day" that some browsers use for Pashto.
- **Units:** `MB`/`KB` are translated in the dictionaries (`مگابایت`, `ميګابايټ`...) but the unit `MB` also appears untranslated inside one error message.
- **Right-to-left punctuation:** check that sentences with Latin words (`Google Sheets`, `Supabase`, `Ariana Smart`, `PDF`) read correctly in the real browser.
- **Not translated at all (by design):** e-mails sent by Supabase (confirmation, password reset), backend error text (the browser maps error codes to the translated messages above), and the browser's own controls (file picker, date picker), which follow the browser language.
